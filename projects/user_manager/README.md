# User Manager

A simple Python project created to practice Object-Oriented Programming (OOP).

## Features

- Create user objects.
- Store usernames and email addresses.
- Check whether an email address ends with `@gmail.com`.
- Display all users with their numbers.
- Count the total number of users.

## Technologies

- Python 3

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python user_manager.py
```

## Concepts Practiced

- Classes and objects
- The `__init__` method
- Instance attributes and methods
- Lists
- Loops and conditional statements
- Functions
- `enumerate()`
