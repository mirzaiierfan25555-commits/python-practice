# Student Manager

A simple Python project for managing student names using text files.

## Features
- Add student names
- Save student names with the current date
- Display students by date
- Handle missing files
- Interactive command-line menu

## Technologies
- Python
- datetime
- File Handling
- Exception Handling

## How to Run

```bash
python student_recorder.py
```
