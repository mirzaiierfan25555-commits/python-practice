# Student Manager CLI

A simple command-line application written in Python to manage a list of students.

## Features

- Add students to the list
- Remove students by name
- Display the student list
- Handle invalid menu choices
- Handle non-numeric menu input
- Check whether a student exists before removing them
- Handle an empty student list

## Requirements

- Python 3

## How to Run

1. Make sure Python 3 is installed on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python student_manager.py
```

## How to Use

When you run the program, you will see a menu:

- `0` — Exit the program
- `1` — Add a student
- `2` — Remove a student

Follow the instructions displayed in the terminal.

## Technologies Used

- Python
- Lists
- Loops
- Conditional statements
- Exception handling

## Current Limitations

- Student names are stored in memory and are lost when the program exits.
- Student names are not saved to a file or database.
