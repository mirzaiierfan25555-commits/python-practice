# Book Manager 📚

A simple Command Line Interface (CLI) application to manage a book library using OOP principles.

## 🚀 Features
- **Add:** Add new books with a title and subject.
- **Remove:** Delete existing books from the list.
- **Edit:** Update book titles and subjects easily.
- **List:** View all books currently in the library.
