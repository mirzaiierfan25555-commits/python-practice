# Vehicle Inheritance — Python OOP Practice

## About
A small Python project created as part of my daily programming practice. It demonstrates basic Object-Oriented Programming (OOP), inheritance, constructors, method overriding, and input validation.

## Concepts Practiced
- Classes and objects
- Inheritance using `Vehicle` and `Car`
- Constructor methods (`__init__`)
- Using `super()` to initialize parent-class attributes
- Method overriding with `get_info()`
- Input validation and loops
- Converting string input to integers

## How It Works
The program asks the user to enter a car model, color, and number of wheels. It validates the wheel-count input and displays the vehicle information. Enter `exit` to stop the program.

## How to Run
```bash
python vehicle_inheritance.py
```

## What I Learned
I practiced extending a parent class with a child class and reusing parent-class functionality with `super()`. I also practiced handling invalid user input.
