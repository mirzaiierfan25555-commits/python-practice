# Average Calculator

A simple and efficient Python script to calculate the average of a list of numbers provided by the user, featuring robust error handling.

## Features
- **Dynamic Input:** Allows users to input numbers.
- **Error Handling:** Uses try-except blocks to handle non-numeric inputs.
- **Clean Code:** Written with readability and maintainability in mind.

## How to Use
1. Ensure you have Python installed.
2. Run the script: `python average_calculator.py`
3. Follow the on-screen prompts.

- Python 3.x
