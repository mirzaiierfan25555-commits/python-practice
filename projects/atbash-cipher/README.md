# Atbash Cipher

A simple Python implementation of the Atbash cipher algorithm.

## Features
- Encrypts and decrypts text using the Atbash cipher.
- Handles both uppercase and lowercase English letters.
- Preserves spaces and punctuation marks.

## How to run
To run this program, simply use the following command in your terminal:
`python atbash_cipher.py`

## What I learned
Through this project, I learned how to use `str.maketrans` for character substitution and improved my skills in string manipulation in Python.
