# Expense Manager CLI

A simple command-line application written in Python to manage daily expenses.

## Features

- **Add Expenses:** Enter an expense amount and its category.
- **List Expenses:** Display all recorded expenses.
- **Calculate Total:** Calculate the total amount of all recorded expenses.
- **Input Validation:** Handle invalid menu choices and non-integer inputs.
- **Simple Menu:** Navigate through the application using numbered options.

## Requirements

- Python 3.x

No external libraries are required.

## How to Run

1. Clone this repository or download the project files.
2. Open a terminal in the project directory.
3. Run the following command:

```bash
python expense_manager.py
```

Replace `expense_manager.py` with your Python file's actual name if it is different.

## Usage

When you run the program, you will see the following menu:

```text
0.stop 1.add 2.list 3.sum
```

Choose an option:

- `0` — Exit the application.
- `1` — Add a new expense with a category.
- `2` — Display all recorded expenses.
- `3` — Calculate the total expenses.
