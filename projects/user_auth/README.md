# Simple Login System 🔐

A basic user authentication simulation built with Python. 

## 📝 About
This project is a command-line interface (CLI) application that simulates a login process using Python dictionaries to store and verify user credentials. It is designed to practice input handling and data lookups.

## 🚀 How it Works
1. The script uses a dictionary (`users`) to store predefined usernames and passwords.
2. It takes input from the user for their username and password.
3. It validates the credentials against the stored data and grants access or displays an error message.

## ⚠️ Important Security Note (Educational Purpose)
This is a **learning exercise**. In real-world production systems:
- Never store passwords in plain text.
- Use secure hashing algorithms (like `bcrypt` or `argon2`).
- Store credentials in secure databases, not in code files.

## 🛠 Features
- Simple `if-else` verification.
- Dictionary-based lookup for efficient credential matching.
- Clean and readable code.
