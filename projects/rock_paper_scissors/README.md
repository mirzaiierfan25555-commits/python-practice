# Rock Paper Scissors

A simple Rock Paper Scissors game built with Python.

## Features
- Play against the computer
- Random computer choices
- Score tracking
- Input validation
- Case-insensitive input
- Type `exit` to quit the game

## Requirements
- Python 3

## How to Run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python rock_paper_scissors.py
```

## Concepts Practiced
- Python functions
- While loops and conditional statements
- Lists and variables
- User input and input validation
- The `random` module

## How to Play
Enter `rock`, `paper`, or `scissors` to play.
The computer randomly selects an option, and the game displays the result and current scores.

Type `exit` to stop playing.
